# Exel-Data-Analysis
Data analysis project using exel
🏦 Loan Management Dashboard | Excel Data Analysis Project

📌 Project Overview

An interactive loan management dashboard built with Microsoft Excel to analyze loan applications, requested amounts, approvals, branch performance, and officer productivity.

The project transforms loan-related data into meaningful KPIs and visual insights, enabling users to explore trends and compare performance across branches, officers, and loan products.

📊 Dashboard KPIs

• Total Sales: 38,506,166.45
• Total Requested Amount: 345,132,306
• Total Cases: 999
• Total Approved Amount: 38,506,166.45

📈 Key Features

1. Branch Performance Analysis

A bar chart presenting sales by branch to support branch-level performance comparisons.

2. Officer Performance Analysis

A pie chart highlighting the top five officers based on the metric used in the dashboard.

3. Monthly Case Trends

A line chart showing the monthly distribution of loan cases throughout 2024.

4. Interactive Filtering

Users can explore the dashboard using slicers and filters for:

• Application date (year and month)
• Loan product:
 • Auto Loan
 • Business Loan
 • Education Loan
 • Home Loan
 • Personal Loan

📁 Workbook Structure

• LoanDetails: Transaction-level loan data, including transaction IDs, customer IDs, product IDs, branch IDs, officer IDs, application dates, disbursement dates, and loan amounts.
• Products: Loan product lookup table.
• Branch: Branch reference information.
• Engine: Supporting calculations and data model.
• Dashboard: Interactive dashboard with KPIs, charts, and filters.

🛠️ Tools & Technologies

• Microsoft Excel
• Power Pivot
• PivotTables
• PivotCharts
• Slicers and Interactive Filters
• Data Analysis and Visualization

🎯 Project Objectives

• Summarize key loan-related metrics.
• Analyze branch and officer performance.
• Explore monthly loan case trends.
• Compare results across loan products and application periods.
• Present data in an accessible, interactive dashboard.

🚀 How to Use

1. Download or clone this repository.
2. Open the Excel workbook in a compatible version of Microsoft Excel.
3. Navigate to the Dashboard worksheet.
4. Use the slicers to filter data by application date and loan product.
5. Explore the KPIs and charts to investigate performance trends.
